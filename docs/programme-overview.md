# Programme Overview

This document provides a high‑level view of the 24‑week curriculum, split into six learning **phases**. Each phase spans roughly four weeks and focuses on a core competency area.

| Phase | Weeks | Core Topics |
|------|------|-------------|
| **Phase 01** | 1‑4 | Programming fundamentals, Unix philosophy, Git mechanics |
| **Phase 02** | 5‑8 | Web fundamentals – HTML, CSS, JavaScript, TypeScript, React |
| **Phase 03** | 9‑12 | Backend development – Python, FastAPI, REST, PostgreSQL |
| **Phase 04** | 13‑16 | Software architecture, system design, testing, debugging |
| **Phase 05** | 17‑20 | DevOps, CI/CD, containerisation, deployment, security |
| **Phase 06** | 21‑24 | Capstone project – full‑stack application, documentation, showcase |

Optional supplemental modules (Data Science, ML, Cybersecurity, Networking) are provided as **resources** in the *Resources* section.

Use the navigation sidebar to dive into each phase for weekly lesson plans, assignments, and project guidelines.

## Technology Stack — Our Engineering Target

The Software Engineering Academy is a 24‑week programme designed to progressively develop competence in the following technology stack.

| Layer | Technology | Purpose |
|---|---|---|
| Language (Backend) | Python | Programming, backend logic, algorithms, automation and application development |
| Language (Frontend) | JavaScript → TypeScript | Browser programming and typed frontend development |
| Frontend | React | Building interactive, component‑based web interfaces |
| Backend | FastAPI | Building REST APIs, backend services and business logic |
| Database | PostgreSQL | Relational database design, SQL, transactions and data persistence |
| ORM | SQLAlchemy | Database integration and object‑relational mapping |
| Database migrations | Alembic | Managing database schema evolution |
| HTML | HTML5 | Web page structure |
| Styling | CSS3 | Layout, responsive design and interface styling |
| Version control | Git | Branching, commits, merges and collaboration |
| Repository hosting | GitHub | Code hosting, pull requests, code reviews and project management |
| Testing | Pytest | Backend unit, integration and API testing |
| Frontend testing | Vitest | Frontend unit and component testing |
| End‑to‑end testing | Playwright | Browser‑based application testing |
| Containers | Docker | Application containerisation |
| Multi‑container orchestration | Docker Compose | Managing local development services |
| CI/CD | GitHub Actions | Automated testing, builds and deployments |
| API documentation | OpenAPI | API contracts and documentation |
| Web security | OWASP guidance | Application security, secure development and threat awareness |
| Deployment | Linux‑based environments and cloud hosting | Deployment, operations and production fundamentals |
