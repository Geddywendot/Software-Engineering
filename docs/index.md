# Home

Welcome to the **Software Engineering Academy** – a comprehensive 24‑week, project‑based learning platform for aspiring software engineers.

---
## Programme Overview
- **Duration:** 24 weeks (6 months)
- **Structure:** Six phases covering foundations, web technologies, backend, full‑stack, professional engineering, and a capstone project.
- **Learning format:** Weekly lessons, hands‑on labs, assignments, projects, and a robust assessment framework.

## Getting Started
1. **Clone the repo**:
   ```bash
   git clone https://github.com/Geddywendot/Software-Engineering.git
   cd Software-Engineering
   ```
2. **Install dependencies** (MkDocs and theme):
   ```bash
   pip install -r requirements.txt
   ```
3. **Run the site locally**:
   ```bash
   mkdocs serve
   ```
   Open <http://127.0.0.1:8000> in your browser.
4. **Contribute** – see the [Contribution Guide](https://github.com/Geddywendot/Software-Engineering/blob/main/.github/CONTRIBUTING.md).
