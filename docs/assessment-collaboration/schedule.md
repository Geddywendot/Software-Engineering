# Weekly Schedule

| Day      | Hours | Activity |
|----------|-------|----------|
| Monday   | 2     | Theory and concepts (lectures, reading) |
| Tuesday  | 2     | Guided coding exercises (in‑class labs) |
| Wednesday| 2     | Independent coding (self‑paced practice) |
| Thursday | 2     | New concepts and implementation (projects) |
| Friday   | 2     | Debugging and testing (bug hunts, unit tests) |
| Saturday | 5     | Project development & pair/group programming |
| Sunday   | 3     | Assessment, documentation and retrospective |

**Total weekly commitment:** **18 hours**.

Learners should log the actual time spent each day in the Learning Journal (see `journal-template.md`).
