# Collaboration System

All three learners follow the **same 24‑week syllabus**. Individual responsibility and teamwork are balanced as follows:

### Individual responsibilities
- **Complete personal exercises** for each week’s laboratory.
- **Maintain a personal contribution log** (see Learning Journal).
- **Submit individual assessments** (assignments, challenges, explanations).

### Collaborative responsibilities
- **Participate in group projects** (Projects 2‑5 and the Capstone).
- **Peer review**: each learner reviews another learner’s pull request (rotating pairings).
- **Technical teaching**: explain concepts to peers during scheduled meetings.
- **Joint coding sessions**: Saturday collaborative programming.

### Contribution tracking
- Each learner works on a personal **feature branch** for their tasks (e.g., `learner-1/week-07-exercise`).
- Pull requests must be **assigned** to the reviewer (the designated peer).
- Review comments are required before merging; reviewers sign‑off with an "LGTM" comment.

The system enforces accountability through the **assessment framework** and **GitHub workflow** described later.
