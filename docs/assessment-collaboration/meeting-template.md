# Meeting Templates

## Monday Planning Meeting
- **Date:** YYYY‑MM‑DD
- **Participants:** Learner 1, Learner 2, Learner 3
- **Objectives:**
  - Review upcoming week's topics and assignments.
  - Align individual schedules.
- **Discussion points:**
  - Clarify any ambiguous concepts.
  - Identify required resources.
- **Decisions:**
  - Assign any preparatory reading.
- **Action items:**
  - Each learner creates a branch for the week’s exercises.
  - Update the shared Kanban board.

## Wednesday Technical Discussion
- **Date:** YYYY‑MM‑DD
- **Participants:** Learner 1, Learner 2, Learner 3
- **Objectives:**
  - Dive deeper into technical challenges encountered.
  - Share solutions and alternative approaches.
- **Discussion points:**
  - Issues from independent coding.
  - Design decisions for project tasks.
- **Decisions:**
  - Agree on best practice for a given problem.
- **Action items:**
  - Refactor code according to decided approach.
  - Document findings in the learning journal.

## Saturday Collaborative Programming
- **Date:** YYYY‑MM‑DD
- **Participants:** Learner 1, Learner 2, Learner 3
- **Objectives:**
  - Jointly develop project features.
  - Conduct pair‑programming sessions.
- **Discussion points:**
  - Task breakdown and ownership.
  - Integration points between modules.
- **Decisions:**
  - Assign pairings and feature responsibilities.
- **Action items:**
  - Merge completed features via pull requests.
  - Record any blockers for follow‑up.

## Sunday Weekly Review
- **Date:** YYYY‑MM‑DD
- **Participants:** Learner 1, Learner 2, Learner 3
- **Objectives:**
  - Evaluate completed work against the weekly rubric.
  - Reflect on learning outcomes.
- **Discussion points:**
  - Assessment scores and feedback.
  - Areas needing improvement.
- **Decisions:**
  - Adjust the upcoming week’s focus if needed.
- **Action items:**
  - Update personal learning journals.
  - Prepare any pending pull requests for review.
