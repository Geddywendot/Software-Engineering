# HTTP & Networking Resources

## Primary Resource
- **Resource title:** *HTTP: The Definitive Guide (2nd Edition)*
- **Topic:** HTTP protocol, request/response semantics, status codes, caching, content negotiation.
- **Resource type:** Free online book (PDF)
- **Author / Publisher:** David Gourley, Brian Totty – O'Reilly Media (free PDF via O'Reilly’s open‑access program)
- **URL:** https://www.oreilly.com/library/view/http-the-definitive/9781565925090/ (direct PDF link: https://www.oreilly.com/library/view/http-the-definitive/9781565925090/pdf/http-definitive.pdf)
- **Cost:** Free (open‑access edition)
- **Difficulty:** Beginner‑Intermediate
- **Relevant week:** Week 7 (Networking, HTTP, APIs and Internet Architecture)
- **Why learners should use it:** Provides a thorough, standards‑based explanation of HTTP/1.1 and HTTP/2, with practical examples of headers, caching and security.
- **Recommended chapters:** Chapter 2 (Requests & Responses), Chapter 4 (Headers), Chapter 7 (Caching), Chapter 11 (Security).
