# System Design Resources

## Primary Resource
- **Resource title:** *System Design Primer*
- **Topic:** Large‑scale system design concepts, scalability, reliability, data modeling.
- **Resource type:** Open‑source guide (GitHub repository)
- **Author / Publisher:** Donne Martin and community contributors
- **URL:** https://github.com/donnemartin/system-design-primer
- **Cost:** Free
- **Difficulty:** Intermediate‑Advanced
- **Relevant week:** Week 21 (Capstone Requirements Engineering and System Design)
- **Why learners should use it:** Provides concise overviews of core concepts (load balancing, caching, databases, messaging) together with interview‑style questions and example designs.
- **Recommended sections:** "Scalability", "Database Design", "Caching", "Message Queues".
