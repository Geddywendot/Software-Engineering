# Application Security Resources

## Primary Resource
- **Resource title:** *OWASP Top Ten – 2021 Edition*
- **Topic:** Common web application security risks and mitigation strategies.
- **Resource type:** Open‑access guide (PDF/HTML)
- **Author / Publisher:** Open Web Application Security Project (OWASP)
- **URL:** https://owasp.org/www-project-top-ten/
- **Cost:** Free
- **Difficulty:** Beginner‑Intermediate
- **Relevant week:** Week 20 (Application Security, Observability and Reliability)
- **Why learners should use it:** Authoritative, industry‑standard checklist of the most critical security weaknesses with concrete remediation advice.
- **Recommended sections:** "A01: Broken Access Control", "A02: Cryptographic Failures", "A07: Identification & Authentication".
