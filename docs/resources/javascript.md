# JavaScript Resources

## Primary Resource
- **Resource title:** *Eloquent JavaScript, 3rd Edition*
- **Topic:** Core JavaScript language fundamentals and modern idioms
- **Resource type:** Free online book (PDF/HTML)
- **Author / Publisher:** Marijn Haverbeke (No Starch Press)
- **URL:** https://eloquentjavascript.net/
- **Cost:** Free (online edition)
- **Difficulty:** Beginner‑Intermediate
- **Relevant week:** Week 6 (JavaScript and Browser Programming)
- **Why learners should use it:** Thorough explanations, interactive examples, and progressive exercises covering syntax, DOM manipulation, and asynchronous programming.
- **Recommended chapters:** Chapter 2 (Basic Types), Chapter 4 (Functions), Chapter 6 (Objects), Chapter 13 (Asynchronous Programming).
