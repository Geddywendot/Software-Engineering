# Software Architecture Resources

## Primary Resource
- **Resource title:** *Software Architecture Patterns*
- **Topic:** Architectural styles, component-based design, layering, microservices.
- **Resource type:** Free online book
- **Author / Publisher:** Mark Richards (O'Reilly Media) – open‑access chapter
- **URL:** https://learning.oreilly.com/library/view/software-architecture-patterns/9781492052205/ (Free preview of chapters 1‑3)
- **Cost:** Free (preview) / Paid for full book
- **Difficulty:** Intermediate
- **Relevant week:** Week 17 (Software Architecture, SOLID and Design Patterns)
- **Why learners should use it:** Clear explanations of common patterns (Layered, Hexagonal, Clean), decision‑making criteria, and real‑world examples.
- **Recommended sections:** Chapter 2 (Layered Architecture), Chapter 4 (Microservices), Chapter 6 (Event‑Driven Architecture).
