# REST APIs Resources

## Primary Resource
- **Resource title:** *REST API Design Rulebook*
- **Topic:** Designing robust RESTful APIs, URI design, versioning, status codes.
- **Resource type:** Free ebook (PDF)
- **Author / Publisher:** Mark Masse (O'Reilly Media) – open‑access edition.
- **URL:** https://www.oreilly.com/library/view/rest-api-design/9781492086848/ (direct PDF: https://www.oreilly.com/library/view/rest-api-design/9781492086848/pdf/rest-api-design.pdf)
- **Cost:** Free
- **Difficulty:** Intermediate
- **Relevant week:** Week 7 (Networking, HTTP, APIs)
- **Why learners should use it:** Concise, pragmatic guidance on URI design, hypermedia, and best‑practice patterns.
- **Recommended sections:** Chapter 3 (Resources & URIs), Chapter 5 (Versioning), Chapter 7 (Error handling).
