# HTML & CSS Resources

## Primary Resource
- **Resource title:** *HTML & CSS: Design and Build Websites*
- **Topic:** HTML & CSS fundamentals and best practices
- **Resource type:** Free online book (OpenStax)
- **Author / Publisher:** OpenStax (Rice University)
- **URL:** https://openstax.org/books/html-css-design-and-build-websites-2e/pages/1-introduction
- **Cost:** Free
- **Difficulty:** Beginner
- **Relevant week:** Week 5 (HTML, CSS and Web Foundations)
- **Why learners should use it:** Comprehensive, peer‑reviewed textbook covering HTML5 semantics, CSS3 layout (Flexbox, Grid), responsive design, and accessibility.
- **Recommended sections:** Chapter 2 (HTML basics), Chapter 4 (CSS selectors), Chapter 6 (Responsive design with media queries).
