# SQL & PostgreSQL Resources

## Primary Resource
- **Resource title:** *PostgreSQL Documentation*
- **Topic:** Official reference for PostgreSQL relational database, SQL syntax, administration.
- **Resource type:** Official documentation (website)
- **Author / Publisher:** PostgreSQL Global Development Group
- **URL:** https://www.postgresql.org/docs/current/index.html
- **Cost:** Free
- **Difficulty:** Beginner‑Intermediate
- **Relevant week:** Week 8 (SQL, Relational Database Design and PostgreSQL)
- **Why learners should use it:** Authoritative, searchable reference covering DDL/DML, indexing, transaction control, and performance tuning.
- **Recommended sections:** "SQL Syntax", "Data Types", "Indexes", "Performance Tips".
