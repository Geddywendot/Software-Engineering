# Software Engineering Academy

Welcome to the **Software Engineering Academy** learning platform. This repository hosts a complete, self‑contained curriculum for three learners over a 24‑week program. It includes:

- Structured weekly syllabus and learning phases
- Lesson, assignment, and project templates
- Detailed documentation built with **MkDocs Material**
- Contribution guidelines, issue templates, and a CI workflow that builds the site on every push

The curriculum covers everything from programming fundamentals to capstone software development, with optional modules in data science, machine learning, cybersecurity, and networking.

> **Note:** All content is written in Markdown and rendered via GitHub Pages using MkDocs.
